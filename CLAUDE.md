# isitlowfodmap.com

Start of every session: read `docs/STATUS.md`, then `docs/DECISIONS.md` (it wins over any plan), `docs/LESSONS.md` and `docs/LAUNCH-CHECKLIST.md`.

Rules:
1. Data rules are non-negotiable: never copy Monash or FODMAP Friendly app data; every number needs a public source; no "low" without lab data. See DECISIONS §0.
2. Next.js 16 has breaking changes: check `node_modules/next/dist/docs/` before using an API you're unsure of.
3. Before every commit: `npm run check`. Small, focused commits.
4. Always reference Mobbin for UI and say which apps a design borrows from. Weigh SEO and return visits in every page decision, no dark patterns.
5. Owner: plain short language, after every step what changed + click-through checklist + phone and PC screenshots; options with scores /10 via the interactive question picker; keys never in chat. Add each checklist to `docs/MANUAL-TESTS.md`.
6. No personal name on pages. Publisher is Grasp Labs LLC.
